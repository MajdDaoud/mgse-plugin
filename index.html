MGSE Beleg – Eclipse Update Repository

Diese Website dient ausschließlich als Eclipse Update Site für die Installation des entwickelten Plug-ins im Rahmen des MGSE-Belegs.

Die bereitgestellten Dateien sind nicht für die direkte Nutzung im Browser vorgesehen. Die Installation erfolgt über Eclipse mittels:

Help → Install New Software → Repository URL einfügen

Bereitgestellte Repository-Dateien

  • site.xml
  • artifacts.jar
  • content.jar
  • features/ (enthält Feature-JARs)
  • plugins/ (enthält Plug-in-JARs)

Dieses Repository wurde entsprechend den Anforderungen aus Aufgabe 5 des Belegs erstellt.
